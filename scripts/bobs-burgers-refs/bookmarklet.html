Copy for Watchlist

A bookmarklet for collecting IMDb Connections pages for the Bob's Burgers watchlist.

Copy for watchlist Drag this button to your bookmarks bar.
  1. On the watchlist page, click an episode's IMDb link to open its Connections page.
  2. Click Copy for watchlist in your bookmarks bar. It adds that page to a batch and copies the whole batch, so you can repeat this for as many episodes as you like.
  3. Import the batch from the repo: 
    pbpaste | python3 scripts/bobs-burgers-refs/import_imdb.py --dry-run
pbpaste | python3 scripts/bobs-burgers-refs/import_imdb.py
  4. Click Clear batch in the bookmarklet's pop-up (or clear it next time you start) so the next batch starts empty. Re-importing pages is harmless: titles already listed are skipped.

It only reads the page you're looking at, the same text you'd select and copy by hand. The batch is kept in your browser's storage for imdb.com.
